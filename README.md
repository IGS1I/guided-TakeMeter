# TakeMeter
A fine-tuned text classifier that evaluates discourse quality in an online community.

Chosen community: Anime (data sourced from My Anime List (MAL))

Idea is to discover the likeliness of enjoyment when watching a show, by classifying reviews into the below labels. Perhaps a rating can be devised by the model and a list of possible pros and cons of a given show.

### Labels
- Fan
- Mixed Feelings
- Hater
